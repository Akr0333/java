# Library Management System

A console-based Java application demonstrating object-oriented design for managing books and members.

## Features
- Add books
- Register members
- Borrow and return books
- Search books
- View available books

## Concepts
Java classes, encapsulation, ArrayList, enums, validation, methods and clean menu-driven application flow.

## Run
```bash
javac LibraryManagementSystem.java
java LibraryManagementSystem
```
