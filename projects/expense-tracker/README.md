# Java Expense Tracker

A console-based expense tracker built to practise Java OOP and clean program structure.

## Features
- Add expenses
- List expenses
- Categorise spending
- Calculate total spending
- Simple command-line menu

## Concepts
- Classes and objects
- Encapsulation
- Collections
- Methods
- Input validation
- Exception handling

The project is intentionally dependency-free and can be run with the standard JDK.
