# Java Projects

A collection of practical Java projects demonstrating core Java, OOP, collections, file handling, exception handling, and basic application development.

## Projects

### 1. Student Management System
A console-based application to add, view, search, update, and delete student records.

**Concepts:** OOP, ArrayList, methods, classes and objects.

### 2. Banking Management System
A simple banking application supporting account creation, deposit, withdrawal, balance checking, and transaction validation.

**Concepts:** Encapsulation, inheritance, exception handling, methods.

### 3. Library Management System
Manage books and members, issue books, return books, and check availability.

**Concepts:** OOP, collections, conditional logic.

### 4. Quiz Application
A command-line multiple-choice quiz with scoring and result calculation.

**Concepts:** Arrays, loops, methods, user input, conditionals.

### 5. Employee Payroll System
Calculate employee salaries using basic salary, allowances, deductions, and net pay.

**Concepts:** Classes, inheritance, polymorphism, calculations.

## Tech Stack
- Java
- Object-Oriented Programming
- Collections Framework
- Exception Handling
- File Handling

## How to Run

Compile a project:

```bash
javac Main.java
```

Run it:

```bash
java Main
```

## Learning Goals

These projects are designed to build practical Java programming skills and prepare for DSA, backend development, and technical interviews.
