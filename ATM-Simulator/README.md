# ATM Simulator 🏧

Console-based ATM simulation demonstrating authentication, balance management and transaction validation.

## Features
- PIN authentication
- Check balance
- Deposit money
- Withdraw money
- Insufficient-balance validation

## Concepts
Methods, conditionals, loops, `Scanner`, validation and state management.

## Run
```bash
javac Main.java
java Main
```

> The PIN is intentionally hard-coded for educational purposes only.
